# Professional Windows Installer Pipeline

## Deliverables
- `BeyondTheNakedEye.exe` (standalone binary runtime)
- `BeyondTheNakedEye_Setup.exe` (full Windows installer)
- `BeyondTheNakedEye_Uninstaller.exe` (generated by Inno Setup in install path)

## Build Workflow

### 1) Build standalone runtime (PyInstaller)
```bash
pyinstaller --noconfirm --clean --onedir --name "BeyondTheNakedEye" -m beyond_naked_eye
```

### 2) Compile professional setup package (Inno Setup)
```powershell
iscc beyond_naked_eye\install\installer.iss
```

## Installer Capabilities
- Installs to `Program Files\Beyond The Naked Eye`
- Registers uninstaller and Apps & Features metadata
- Creates Start Menu and optional Desktop/Quick Launch shortcuts
- Creates program and user runtime directory trees
- Includes setup wizard pages, license page, progress, and installation diagnostics log page
- Launches installed binary immediately after setup (optional)

## First-Launch Initialization
At first launch, application bootstrap automatically:
- creates user config/session/cache/history/log directories in `%APPDATA%\BeyondTheNakedEye`
- ensures program cache/database/log/export/session/plugin directories exist
- initializes local `database\bne.db`
- writes default CRT theme config (`configs/default.json`)
