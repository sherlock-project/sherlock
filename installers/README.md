# Committed Windows Installer

This folder is where the latest built `BeyondTheNakedEye_Setup.exe` installer is committed by GitHub Actions.

- Workflow: `.github/workflows/commit-windows-exe.yml`
- Run it from **Actions → Commit Windows Installer to Repository**.
- After workflow success, these files are committed:
  - `installers/BeyondTheNakedEye_Setup.exe`
  - `installers/BeyondTheNakedEye_Setup.exe.sha256`
